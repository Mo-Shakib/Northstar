# Northstar logo assets

The final identity is supplied as outlined SVG artwork. No font files are required at runtime.

## Files

| File | Description |
|---|---|
| `northstar-logo.svg` | Primary horizontal lockup on light surfaces |
| `northstar-logo.png` | Transparent raster export of the primary lockup |
| `northstar-logo-reverse.svg` | Lockup for Evergreen/dark surfaces |
| `northstar-logo-mono.svg` | One-ink version for light stock |
| `northstar-logo-mono-reverse.svg` | One-ink version for dark stock |
| `northstar-logo-compact.svg` | Mark and wordmark without descriptor |
| `northstar-logo-stacked.svg` | Vertical lockup for narrow/square placements |
| `northstar-mark.svg` | App/brand mark |
| `northstar-mark-reverse.svg` | Mark for dark surfaces |
| `northstar-mark-mono.svg` | One-ink mark |
| `northstar-mark-mono-reverse.svg` | One-ink mark for dark stock |
| `northstar-favicon.png` | 512 px favicon/app icon |
| `northstar-favicon-64.png` | 64 px favicon |
| `northstar-favicon.ico` | Multi-size browser icon |

Usage, clearspace, palette and typography details live in [the brand guide](../docs/brand.md).

## Typefaces

The wordmark is outlined from **Fraunces** (SIL Open Font License 1.1) and the descriptor from **Instrument Sans** (SIL Open Font License 1.1). License texts are in [`licenses/`](licenses/).
